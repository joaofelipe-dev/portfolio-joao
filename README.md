Repositório do meu portfólio pessoal. Frontend com Next.js, priorizando performance real (Core Web Vitals) em vez de só aparência.

**Link:** [jfelipe.dev](https://jfelipe.dev)

---

## Stack

- **Framework:** [Next.js 14+](https://nextjs.org/) (App Router)
- **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
- **Linguagem:** JavaScript (ES6+)
- **Componentes de UI:** Radix UI / Shadcn UI
- **Ícones:** Lucide React
- **Deploy:** Vercel

---

## Decisões técnicas

- **Performance:** `next/font` e carregamento otimizado de imagens — sem depender só do Lighthouse de exemplo.
- **Tema claro/escuro:** respeita preferência do sistema, com troca manual.
- **Dados reais:** seções de projeto puxam informação real (ex: GitHub API), sem métricas fictícias.
- **Responsivo:** mobile, tablet e desktop testados manualmente, não só via breakpoint padrão.
